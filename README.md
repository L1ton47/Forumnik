# Forumnik 1.4

Настольная программа для подготовки жалоб на форум Radmir. Интерфейс — HTML/CSS/JavaScript, отдельное окно — Python и pywebview.

## Запуск через VS Code

1. Открой папку `Forumnik_1.3` через **File → Open Folder**.
2. Открой **Terminal → New Terminal**.
3. Один раз установи зависимость:

   ```powershell
   python -m pip install -r requirements.txt
   ```

4. Запусти программу:

   ```powershell
   python main.py
   ```

## Что нового в 1.3

- Убраны BBCode-теги `[B][I]` из шаблонов ФСИН, ФСБ и МВД сервера 04. Текст теперь копируется обычным читаемым текстом без служебных тегов.
- Сохранены отдельные формулировки шаблонов ФСИН, ФСБ и МВД по образцу, который предоставил пользователь.
- Добавлены пояснения к полям простым языком.
- Добавлена раскрывающаяся инструкция по созданию жалобы.
- Добавлено автоматическое сохранение черновика отдельно для каждого сервера и категории на этом ПК.
- Добавлен счётчик символов для многострочных полей.
- Для поля даты добавлен календарь и кнопка «Сегодня».
- Добавлена выгрузка готовой жалобы в TXT и улучшено копирование в буфер обмена.
- Очистка формы удаляет также сохранённый черновик текущей категории.
- Версия проекта — 1.3.

Данные черновиков хранятся локально в хранилище приложения. Программа не отправляет жалобы на форум и не передаёт текст на сервер Forumnik. Всегда проверяй актуальные требования конкретного раздела форума перед публикацией.
