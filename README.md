# Forumnik 1.5

Настольная программа для подготовки жалоб на форум Radmir (CRMP). Интерфейс — HTML/CSS/JavaScript на русском языке, окно — Python + pywebview. Всё работает локально.

## Запуск

```powershell
python -m pip install -r requirements.txt
python main.py
```

`pystray` и `Pillow` нужны только для трея; без них программа работает, а опция трея отключена.

## Что нового в 1.5

- **Серверы 06–10 — базовый набор категорий** (`ui/schemes_new.js`). Точные разделы форума для них нужно сверить и при необходимости заменить; в программе они помечены значком ◐.
- Профили, быстрое заполнение, копирование отдельных полей, редактирование готового текста, заметки.
- Избранное, черновики, история, папки, архив, закрепление, поиск.
- Кнопка «Скопировать и открыть форум», ссылки на разделы для каждого сервера и категории (Настройки → Ссылки на разделы или `ui/config.js`).
- Главная с виджетами и быстрыми действиями, оформление (цвета, анимации, экран загрузки).
- Центр обновлений (проверка GitHub Releases), новости, история версий, список серверов, инструкция, страница разработчика, центр ссылок, внутренние сообщения.
- Трей, автозапуск, подтверждение выхода, восстановление после сбоя, горячие клавиши.
- Резервные копии, экспорт/импорт настроек, статистика, управление данными.

Данные хранятся в `%APPDATA%\Forumnik\data.json`, копии — в `%APPDATA%\Forumnik\backups`.

## Что нужно заполнить вручную (ui/config.js)

- `CATEGORY_LINKS` / `SERVER_LINKS` — адреса создания тем (или задай их в Настройках).
- `DEVELOPER` — Telegram, Discord, VK. Пустые значения показываются как «не указан».
- `SUPPORT_LINK` — ссылка для поддержки.
