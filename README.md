# Forumnik 1.3

**Forumnik** — неофициальная настольная программа-помощник для подготовки жалоб на форум Radmir. Программа собирает текст из заполненных полей, показывает предварительный просмотр и позволяет скопировать его или сохранить в TXT.

> Forumnik — независимый пользовательский проект. Он не связан с администрацией Radmir и не отправляет жалобы на форум автоматически. Перед публикацией проверяйте актуальные правила нужного раздела.

## Скачать и запустить

1. Откройте вкладку **Releases** в этом репозитории.
2. Выберите последнюю версию Forumnik.
3. Скачайте файл **Forumnik.exe** из раздела Assets.
4. Запустите его на Windows.

Если Windows сообщает, что WebView2 Runtime отсутствует, установите официальный Microsoft Edge WebView2 Runtime: https://developer.microsoft.com/microsoft-edge/webview2/

Не отключайте антивирус или защиту Windows ради запуска программы. Если файл вызывает предупреждение, сначала проверьте источник и сообщите автору.

## Функции версии 1.3

- Подготовка жалоб по доступным серверам и категориям.
- Отдельные шаблоны МВД, ФСБ и ФСИН для сервера 04 по предоставленному образцу.
- Предварительный просмотр готового текста.
- Копирование текста и сохранение в TXT.
- Автосохранение черновиков на этом компьютере.
- Пояснения к полям и счётчик символов.

## Для разработчиков: запуск из исходного кода

Требуется Python 3.10 или новее.

```powershell
python -m pip install -r requirements.txt
python main.py
```

## Сборка Windows EXE

В репозитории есть GitHub Actions workflow: `.github/workflows/build-windows-release.yml`.

- При публикации GitHub Release workflow собирает `Forumnik.exe` на Windows runner и прикрепляет файл к релизу.
- При ручном запуске workflow через **Actions → Build Windows release → Run workflow** EXE сохраняется как build artifact.

Локальная сборка на Windows:

```powershell
python -m pip install -r requirements.txt pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name Forumnik --add-data "ui;ui" --collect-all webview main.py
```

Готовый файл появится в `dist/Forumnik.exe`.

## Конфиденциальность

Программа работает локально. Черновики сохраняются в локальном хранилище окна приложения на этом компьютере. Не вводите в программу пароли от игровых аккаунтов или другие секретные данные.
