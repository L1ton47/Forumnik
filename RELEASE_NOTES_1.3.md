# Forumnik 1.3

Первая публичная версия для тестирования.

### Возможности
- Подготовка текста жалоб по выбранному серверу и категории.
- Шаблоны МВД, ФСБ и ФСИН для сервера 04 по предоставленным образцам.
- Предварительный просмотр, копирование и экспорт TXT.
- Автосохранение черновиков на компьютере.
- Подсказки к полям, календарь и счётчик символов.

### Важно
Forumnik — неофициальный помощник. Он не связан с Radmir и не отправляет жалобы автоматически. Перед отправкой проверьте данные и актуальные правила форума.

### Совместимость
Windows x64. Для отображения интерфейса может потребоваться Microsoft Edge WebView2 Runtime.
